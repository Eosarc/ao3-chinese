# PR #69 回复建议（二）：术语表格式规范与解析修复

> 适用场景：作为 PR #69 的 Review 审查意见或回复。
> 处理原则：完全尊重译者与同人圈读者习惯的译文用词（保留“猛烈撞击”、“射门违例”、“换班”、“球饼”等所有译名），仅修复会导致 AOT 插件语法解析报错、词条丢弃或匹配失效的技术问题。

---

看到这次补充了好多新角色（如让-雅克、维克托、副队长等）以及“争球圈”、“反手击球”等新词 🎉

在合并前，插件在离线解析这份文件时检测到了几处格式语法上的小问题。由于 AOT 的底层解析规则比较严格，为了避免词条被插件丢弃或无法匹配，建议对以下几处做简单调整：

---

#### 1. 补齐缺失的冒号

有 2 行词条漏掉了冒号分隔符，插件找不到冒号会判定为语法错误并直接丢弃该行，导致正文中这些词无法翻译。

* 原文：`Svetlana Vetrova 斯韦特兰娜 韦特罗娃`
  建议改为：`Svetlana Vetrova：斯韦特兰娜 韦特罗娃`
* 原文：`Boston Bears 波士顿 熊队`
  建议改为：`Boston Bears：波士顿 熊队`

---

#### 2. 拆分斜杠 `/` 词条

AOT 插件不支持在英文原文中使用斜杠表示“或者”。插件会把带有斜杠的整串文字当作一整个长词，导致小说里单独出现 `Goalie` 或 `Goaltender` 时全都无法命中翻译。

* 原文：`Goalie / Goaltender：守门员`
* 建议拆成两行：
  ```txt
  Goalie：守门员
  Goaltender：守门员
  ```

---

#### 3. 更新时间格式建议

* 原文：`更新时间：02-11-2026`
* 建议：`02-11-2026` 容易让人混淆是“2月11日”（美式）还是“11月2日”（英式）。建议使用无歧义的国际标准格式（年-月-日）：`更新时间：2026-11-02`

---

#### 4. 重复词条与 `=` 语法

* 去重：
  `Troy Barrett：特洛伊 巴雷特` 在人名区出现了两次，可删除一条冗余项。
* 多词关联 `=` 语法：
  如果希望在小说中单独出现主角姓氏（如仅出现 `Hollander` 或 `Rozanov`）时也能被自动翻译，可以利用 AOT 的等号语法：
  `Shane Hollander = 谢恩·霍兰德`
  插件会自动分解并识别全名、单名 Shane、单姓 Hollander。
  > 注：如果你更倾向于只有出现全名时才翻译，或者单独的名已在下方单列，那么继续保持当前的 `:` 规则即可，按你的阅读偏好来决定！
